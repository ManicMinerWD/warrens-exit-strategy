What to log for each listing

When a buyer sends a link, capture these fields in data.js COMPETITION_TRACKER:

FieldWhat to capture
titleShort label — e.g. "REA Melbourne apartment #151850872"
urlFull listing URL — this is the primary key; can always re-visit
sourcePlatform — realestate.com.au, domain.com.au, laudus, facebook, etc.
typeApartment / townhouse / house / land / villa
locationSuburb + state — e.g. "Melbourne VIC", "Carlton VIC 3053"
bedsBedroom count — null if unclear
priceAsking price in AUD (null if not stated — note if auction/price-guide)
lastSeenDate we logged it — YYYY-MM-DD
buyerContextWho mentioned it, what they said, where in the funnel this buyer is
notesAny extra detail — auction date, features, why it caught our eye
statuslogged / researched / compared / dropped
actionWhat we need to do next — extract field X, compare to our property Y, call the agent

How to add a competitor to the tracker

Add an entry to the COMPETITION_TRACKER array in data.js:

{ id: "rea-melbourne-apartment-151850872", // short unique id title: "Melbourne apartment — REA listing #151850872", url: "https://www.realestate.com.au/property-apartment-vic-melbourne-151850872", source: "realestate.com.au", type: "Apartment", location: "Melbourne VIC", beds: null, // null if not stated price: null, // null if not stated (note auction/price-guide in notes) lastSeen: "2026-09-20", buyerContext: "Potential buyer reported this — tracking alongside G05/108 + 302/108", notes: "", status: "logged", action: "Extract price, beds, suburb, auction/price-guide; compare to G05/108 ($420k est.) and 302/108 ($420k est.)" }

Then commit + push — the site rebuilds automatically on GitHub Pages. The table above updates immediately.
